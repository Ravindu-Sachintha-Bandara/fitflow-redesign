# Tech Stack Summary
| Layer | Technology | Reason |
|---|---|---|
| Frontend | Flutter | One codebase for iOS, Android, web; near-native performance |
| Core backend | NestJS | Modular TypeScript, real-time gateway, team productivity |
| AI service | FastAPI | Python ML ecosystem; independent scaling |
| Database | PostgreSQL + Redis + S3 | Integrity, analytics, caching, media |
| Auth | AWS Cognito | Compliance-ready, low cost, standards-based tokens |
| Hosting/CI | AWS ECS Fargate, GitHub Actions | Managed containers, automated pipelines |
